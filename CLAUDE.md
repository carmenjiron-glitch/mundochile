# REGLAS OBLIGATORIAS — MUNDOCHILE

## Antes de cada cambio
1. Leer el código exacto que se va a tocar
2. Mostrar qué líneas se modificarán antes de hacerlo
3. Confirmar que nada fuera de esas líneas será afectado

## Después de cada cambio
4. Reportar exactamente qué líneas se tocaron
5. Confirmar que nada más fue modificado
6. Hacer build limpio antes de commit

## Prohibido siempre
- Agregar, mover, renombrar o cambiar cualquier elemento no mencionado
- Hacer cambios "de paso" o "mientras estoy aquí"
- Commitear sin build limpio
- Modificar más de un componente sin confirmación explícita

## Al inicio de cada sesión
- Verificar que guardar evento, guardar cliente y guardar intérprete funcionan antes de cualquier cambio
